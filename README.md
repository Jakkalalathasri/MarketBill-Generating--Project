 
# Market Bill Generating System

A Python-based project designed to calculate item costs and generate market bills based on product quantities and prices.

## Overview

The Market Bill Generating System demonstrates how Python can simplify basic billing operations by calculating totals for purchased items.

## Features

- Add product names, quantities, and prices
- Calculate item-wise costs and total bills
- Display billing information clearly
- Reduce manual calculation errors

## Technologies Used

- Python
- Lists and Dictionaries
- Loops and Conditional Statements
- Basic Arithmetic Operations

## How It Works

1. Enter the product details.
2. Provide the quantity and price for each item.
3. Calculate the cost of each item.
4. Display the total bill.

## Learning Outcomes

- Practiced Python data structures
- Improved problem-solving skills
- Applied loops and arithmetic operations to a practical use case
